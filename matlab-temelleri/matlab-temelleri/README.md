## Öğrenme hedefleri

- Çalışma ortamını düzenlemek; değişken, vektör ve matris oluşturmak.
- Elemanlara erişmek, bölgeler seçmek ve değerleri değiştirmek.
- Matris işlemleri ile eleman bazlı işlemleri ayırt etmek.
- Koşul ve döngülerle matrisler üzerinde işlem yapmak.

## Başlangıç

1. Depoyu ZIP olarak indirip çıkarınız veya kendi GitHub adresinizden klonlayınız.
2. MATLAB’da proje klasörünü Current Folder olarak seçiniz.
3. Aşağıdaki dersleri sırayla açınız.
4. Her dersin `ornek.m` dosyasını Editor’da açıp **Run** ile çalıştırınız.
5. Değişkenleri Workspace’te, çıktıları Command Window’da inceleyiniz.
6. Ders sonundaki uygulamayı kendiniz çözünüz; ardından çözümlerle karşılaştırınız.

Temel örnekler MATLAB ile çalışır; Image Processing Toolbox gerektirmez. Her örnek dosyası ihtiyaç duyduğu değişkenleri tanımlar. `sum(A(:))` tüm elemanları toplar; yeni sürümlerde `sum(A,"all")` da kullanılabilir.
