# 07. Matris Elemanlarına Erişim

İndisler 1’den başlar. A(satır,sütun) ile tek elemana erişilir.

## Örnek kod

```matlab
A = [10 20 30;40 50 60;70 80 90];
disp(A(1,1)) % 10
disp(A(2,3)) % 60
disp(A(3,2)) % 80
```

## Uygulama

A(2,1) değerini bulunuz. Beklenen: 40.
