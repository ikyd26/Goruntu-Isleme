# 15. for Döngüsü

Döngü değişkeni belirtilen vektörün değerlerini sırayla alır.

## Örnek kod

```matlab
for i = 1:5
    disp(i)
end
for i = 2:2:10
    disp(i) % 2 4 6 8 10
end
for i = 1:5:100
    disp(i) % Son değer 96, toplam 20 adım
end
```

## Uygulama

1’den 99’a kadar tek sayıları yazdırınız.
