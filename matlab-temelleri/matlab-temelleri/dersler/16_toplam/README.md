# 16. Döngü ile Toplam Hesaplama

Biriktirme değişkeni döngüden önce başlatılır. Her adımda yeni değer mevcut toplama eklenir.

## Örnek kod

```matlab
toplam = 0;
for i = 1:10
    toplam = toplam+i;
end
disp(toplam) % 55
```

## Uygulama

1’den 100’e kadar çift sayıların toplamını bulunuz. Beklenen: 2550.
